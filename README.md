# Alireza Ahmadi — portfolio

**▶ Live: https://awlirezaz.github.io/** · [Résumé PDF](https://awlirezaz.github.io/Alireza-Ahmadi-Portfolio.pdf)

Backend developer (.NET) in Tehran. This repo is my portfolio site: one hand-written `index.html`
(no framework, no build step) with project screenshots in `assets/`.

## Updating it

1. Edit `index.html` (or swap images in `assets/`).
2. Push to `main`. [.github/workflows/pages.yml](.github/workflows/pages.yml) publishes it automatically.

## Regenerating the PDF

The page has a print stylesheet, so the PDF is just the page printed:
open the live site in Chrome or Edge → **Print** → **Save as PDF** → paper size **A4**,
margins **Default**, **Background graphics** on → save as `Alireza-Ahmadi-Portfolio.pdf` in this folder.
